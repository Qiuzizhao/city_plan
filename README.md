# 迷你城市规划师 (Mini City Planner)

这是一个基于 Web 的 3D 城市规划演示应用，用户可以在浏览器中自由规划和构建属于自己的迷你城市。项目使用 HTML5、CSS (Tailwind CSS) 和 JavaScript (Three.js) 构建，无需安装任何额外环境，打开网页即可体验。

## 主要功能
- **丰富的建筑与设施模型**：包含住宅、多样式商业楼（如经典长方体、春笋大厦、上海中心大厦、平安金融中心等）、医院、学校、消防局、游乐园、东方明珠塔等。同种建筑支持点击无缝切换样式。
- **真实的物理交通系统**：铺设道路后会自动生成行驶的小汽车和公交车。交通系统基于真实的双车道物理逻辑构建，车辆严格靠右行驶，并在路口进行精确的车道交点转向与掉头。
- **全端适配交互**：针对桌面端与移动端分别进行了操作优化，支持移动端单指点击建造、单指滑动旋转视角、双指缩放等直觉操作。
- **动态天气与昼夜交替**：支持一键切换晴天/雨天以及白天/黑夜模式，天空中配有动态云层，夜景模式下建筑、云层和车辆会自动亮起灯光。
- **城市规划评估**：内置智能评估系统，根据城市中的建筑比例、绿化程度、交通便利性等给出规划评分和建议。
- **存档与读取**：支持将当前的城市布局导出为 JSON 文件并保存到本地，随时可以导入继续编辑。

## 技术栈
- **Three.js**：用于 3D 场景渲染和动画。
- **Tailwind CSS**：用于快速构建现代化的 UI 界面。
