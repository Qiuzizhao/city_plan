# 立体交通与桥梁系统设计方案 (3D Traffic & Bridge System Design)

## 1. 摘要 (Summary)
当前城市的交通系统是纯二维平面的（仅有 X 和 Z 轴，Y 轴恒为 0）。
本设计方案旨在将交通系统升级为**真正的三维立体交通**。玩家可以选中任何形式的道路（直道、弯道、路口），通过操作改变其高度（Y 轴），将其升格为桥梁（高架桥）。桥梁支持多层堆叠，且允许下方存在其他建筑或水面。相邻不同高度的道路会自动生成“坡道”进行连接。汽车将在三维空间中平滑行驶，包括上坡、下坡以及在不同高度的立交桥上穿梭，而不会与底层的建筑发生物理或逻辑上的冲突。

## 2. 核心架构重构 (Architecture Refactoring)

### 2.1 底层数据结构升级 (True 3D Storage)
为了支持“桥底有房”和“多层高架”，当前的二维哈希表 `cityMap`（键为 `x,z`，值为单一对象）必须升级为三维存储结构。
- **方案**：将 `cityMap` 的键值对中的“值”由单个对象改为**数组**，或者将键名升级为三维坐标 `x,y,z`（推荐使用 `x,y,z` 以便于精确查找）。
- **具体结构**：`cityMap.set("x,y,z", object)`，其中 `y` 代表离散的高度层级（Level）。
  - Level 0 (Y=0): 地面层（草地、水面、普通道路、基础建筑）。
  - Level 1 (Y=1): 一层高架桥（高度设定为 1 个建筑单位高度，如 1.5 对应的实际 Three.js 坐标）。
  - Level 2 (Y=2): 二层高架桥...以此类推。

### 2.2 道路高度属性与桥梁形态 (Elevation & Visuals)
- **概念统一**：不再将“桥梁”视为一种单独的工具，而是作为所有“道路”的一种**状态属性**（即 Level > 0 的道路就是高架桥）。
- **视觉生成**：
  - 当道路被提升（Level > 0）时，其渲染函数除了生成路面外，会自动在其下方生成**桥墩**（延伸至下一层坚固支撑面或地面），并在两侧生成**护栏**。
  - **冲突检测**：在提升高度前，必须检测该位置对应高度层是否已有建筑（防止“穿房而过”的诡异状况）。建筑的 `height` 属性将决定它占据了多少个 Level。

## 3. 坡道自动生成机制 (Auto-Ramp Generation)

汽车要开上高处的桥梁，必须通过物理坡道。
- **自动检测与连接**：当玩家改变某段道路的高度后，系统会触发一次局部路网更新（Graph Update）。
  - 检查相邻的四个网格。如果发现相邻格子上存在道路，且它们的高度差刚好为 **1 个 Level**（且朝向匹配），系统将自动把较低的那段道路转换为**坡道（Ramp）**。
- **坡道模型**：坡道是一种特殊的直路，其 3D 模型将在 Z 轴或 X 轴上发生倾斜（Pitch 旋转），一端连接低层，一端连接高层。
- **坡度设计**：假设 1 个格子宽度为 `1`，1 个 Level 的高度差也为 `H`，那么坡度为 `Math.atan(H / 1)`。为了视觉合理性，1 个 Level 的物理高度不宜过高（例如设为 0.5 到 0.8），否则坡度太陡汽车开不上去。

## 4. 汽车 3D 运动逻辑重构 (3D Car Movement)

目前的汽车仅在 X-Z 平面通过 `Vector3(vx, 0, vz)` 移动，Y 轴始终为 0。
- **Y 轴引入速度向量**：汽车的 `velocity` 必须包含 Y 轴分量。
- **坡道行驶逻辑**：
  - 当汽车驶入“坡道”网格时，根据坡道的倾斜方向和车辆的行驶方向，自动计算并赋予 `velocity.y`。
  - 汽车的车身模型（Mesh）需要根据坡度自动进行 Pitch 旋转（车头抬起或低头），以贴合路面。
- **高架桥行驶**：当汽车在高架桥（Level > 0 的平路）上行驶时，其 `velocity.y = 0`，但其绝对坐标 `position.y` 将等于该层的高架桥路面高度。这样可以完美解决“在桥底行驶”的视觉 Bug。
- **多层导航决策**：由于存在多层立交，汽车在路口决策时（`updateTraffic`），不仅要读取 `x,z` 还要读取当前所在的 `y` 层级（`currentGridKey = "x,y,z"`），确保它只会在自己所在的立交桥层进行转弯或直行，绝不会跨层瞬移。

## 5. 交互逻辑扩展 (Interaction Flow)

如何在不增加复杂 UI 的情况下让玩家改变道路高度？
- **“提升/下降”工具**：在左侧工具栏新增两个按钮（如 ⬆️ 和 ⬇️）。
  - 选中 ⬆️ 时，点击地图上现有的道路，将其高度层级 +1。
  - 选中 ⬇️ 时，点击高架桥，将其高度层级 -1。
- 或者 **长按拖拽**（类似《都市天际线》）：选中“指针”工具，点击并按住现有的道路，垂直向上或向下拖动鼠标，道路即随着网格吸附“咔哒”一声升降高度（此方案实现较复杂，推荐先用按钮方式）。

## 6. 验证与验收标准 (Acceptance Criteria)
1. **多层共存**：确认能在水面或低层建筑正上方建立高架桥，且互不干扰。
2. **坡道生成**：确认相邻不同高度的道路能自动生成倾斜的坡道路面，且没有裂缝。
3. **三维行驶**：观察汽车能否平滑地沿着坡道开上高架桥，车头是否正确倾斜，且在高架桥上行驶时高度正确（不穿模）。
4. **立交桥交叉**：十字交叉的两条高架桥（一条 Level 1，一条 Level 2）应互不影响，下方车辆能顺利从上方车辆底盘下穿过。
